# Changelog

All notable changes to the Did You? prototype are recorded here.

## [0.1.0] — 2026-11-20

### Added
- Responsive 5-tab social app prototype with swipe cards
- Example questions spanning funny, dark, personal, travel, wholesome, relationships, and fitness topics
- Question communities, stories, replies, likes, and local sample publishing
- Search, filters, and trending discovery
- Create-a-question flow, bookmarks, bucket list, and private answer history
- Browser-local persistence, anonymous sample posting, and dark-topic visibility setting

### Deployment
- GitHub-ready `index.html` entrypoint
- Render Static Site configuration and update instructions

> This is a demo with fictional activity and local-only state.
